# Модуль 4. Заказы

Реализовано:

- Кнопка «Заказы» для менеджера и администратора.
- Просмотр списка заказов по макету: артикул, статус, адрес пункта выдачи, дата заказа, дата поставки/выдачи.
- Для администратора:
  - добавление заказа;
  - редактирование заказа;
  - удаление заказа.
- После изменения данных список заказов обновляется.
- Статус заказа и пункт выдачи выбираются из выпадающих списков.
