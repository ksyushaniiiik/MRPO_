# Модуль 2. Алгоритм и базовое приложение

Реализовано:

- Окно входа при запуске приложения.
- Авторизация по логину и паролю из таблицы `users`.
- Вход в роли гостя.
- Определение роли пользователя после входа.
- Отображение ФИО и роли в правом верхнем углу.
- Возврат на экран входа через кнопку «Выход».
- Единый стиль интерфейса: Times New Roman, белый фон, дополнительный зеленый фон, акцентный цвет.
- Документ с блок-схемой алгоритма: `docs/module_2_algorithm_flowchart.pdf`.
