# Модуль 3. Товары, интерфейс, поиск и CRUD

Реализовано:

- Последовательный интерфейс с переходами между товарами и заказами.
- Список товаров из БД.
- Карточка товара: фото, категория, название, описание, производитель, поставщик, цена, единица измерения, количество, скидка.
- Заглушка `resources/picture.png`, если изображение товара отсутствует.
- Подсветка товара:
  - скидка больше 15% — фон `#2E8B57`;
  - нет на складе — голубой фон;
  - при скидке старая цена красная и зачеркнутая, новая цена черная.
- Для менеджера и администратора:
  - поиск по текстовым полям;
  - сортировка по количеству на складе;
  - фильтр по поставщику;
  - совместная работа поиска, сортировки и фильтра.
- Для администратора:
  - добавление товара;
  - редактирование товара;
  - удаление товара;
  - запрет удаления товара, который присутствует в заказе;
  - сохранение/замена изображения в папку `resources/images`;
  - ограничение изображения до 300x200 px при наличии Pillow.
