# Модуль 1. База данных

Реализовано:

- Схема БД в 3НФ для магазина обуви.
- Первичные ключи для всех сущностей.
- Внешние ключи и ссылочная целостность.
- Ограничения на неотрицательную цену, количество и скидку.
- Отдельные справочники: роли, категории, производители, поставщики, единицы измерения, статусы заказов, пункты выдачи.
- Связь `products -> order_items` настроена с ограничением удаления: товар, который есть в заказе, нельзя удалить.

Файлы:

- `database/schema.sql` — создание таблиц и связей.
- `database/seed.sql` — базовые справочники.
- `database/import_from_excel.py` — импорт данных из Excel-файлов приложения 2.
- `docs/module_1_er_diagram.pdf` — ER-диаграмма.
